About ChainGuard

A senior research project re-imagining how SOCs collaborate.

The Problem

Modern SOCs work in isolation. When one organization detects a malicious IP, others remain blind until they're attacked themselves. Centralized threat-intel platforms create trust bottlenecks and stale data.

The Solution

A permissioned Hyperledger Fabric network where every SOC is a peer. IoCs are sanitized, signed, and committed via chaincode — propagated to all members within seconds.

Tech Stack

  • Hyperledger Fabric — Permissioned blockchain
  • Chaincode (Go / Node.js) — Smart contract logic
  • Python 3 — Node agents (detect & listen)
  • Flask — Optional REST gateway
  • SQLite — Local cache
  • Docker + Compose — Deployment
